# Portal Xipp

Portal fiscal da **Xipp**: Tributos, Y570 · ECF, Consulta CNPJ e SN e
Consulta CPF, com login, Admin de usuários e Cadastro de empresas. Saiu do
`portal-fiscal-modelo` (ver `MODELO.md`).

- Implantação (Supabase, Vercel, primeiro acesso): `NOVO-PORTAL.md`.
- Arquitetura, segurança e regras: `CLAUDE.md`.
- Instância do Tributos: `liliane-hiramoto/xipp-tributos-web`.

Dev: `npm run dev -- -p 3900`.
